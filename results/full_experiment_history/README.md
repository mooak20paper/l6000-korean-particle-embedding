## 집계와 해석

5,000건 자료 단계와 seed 17·42·73의 동일 조건 3회 반복은 계획의 일부였으나 이 완료 목록의 실험으로 추가하지 않았다. 별도로 L6000과 같은 학습 설정에서 seed 42·123·2026·3407 네 차례의 학습 및 Validation·검증용 KorSTS 평가를 완료하였고, 같은 Test600·KLUE-STS519에서도 평가하였다. 기존 Test의 반복 평가이므로 결과를 독립 확증으로 해석하지 않는다.

이 파일은 논문에서 분리한 상세 수치 이력이며, 새로운 학습이나 추론을 실행한 결과가 아니다. 수치는 원래 표의 문자열을 그대로 보존하였다. 추가 네 seed의 결과는 [별도 seed 평가 기록](../seeds/summary.json)을 따른다. 원시 로그·입력·검수 기록과 해시의 기존 보존 및 평가 격리는 유지한다.
