# KorSTS 보존 입력 2,000쌍

일반 문장쌍에 대한 고정 BGE-M3의 교사 cosine을 보존하기 위한 학습 입력이다. 개발·외부 평가 STS와 구분한다.

| 항목 | 고정 보존 기록 |
|---|---|
| 문항 또는 문장쌍 수 | 2,000 |
| SHA-256 | `92eb8409502345de810c58b2e4871a254c2ecbe1efefd0c7bfbc0bf21237348d` |
| 원본 파일 바이트 | 1,196,890 |
| 역할 | Frozen teacher cosine targets; KorSTS train |
| 문장 원문 공개 | 미포함 |

이 페이지는 실제 원본 입력의 구성과 식별 해시를 안내한다. 원본 문장이나 사람 검수 기록을 다운로드하는 링크가 아니다. 원본 입력은 별도 보존하며 접근·이용 조건은 [데이터 제공 안내](../DATA_AVAILABILITY.md)를 따른다.
